# Punk Hazard Expansion

Adds a detailed Punk Hazard island and new bosses to One Piece ASA Modified V87

## Features

- Detailed Punk Hazard island with half frozen, half volcanic terrain
- Caesar Clown lab structure
- New boss entities: Vergo, Caesar Clown, and Monet with unique textures and animations

## Requirements

- Minecraft Bedrock Edition (version 1.16.0 or higher)
- One Piece ASA Modified V87

## Installation

1. Download the addon files
2. Place the addon folder in your Minecraft Bedrock Edition's addons folder
3. Enable the addon in Minecraft settings

## Usage

Once installed, the Punk Hazard island will generate in your world, and you can encounter the new boss entities in their respective locations.

## Configuration

The addon does not include configuration files. All settings are hardcoded in the manifest and entity files.
